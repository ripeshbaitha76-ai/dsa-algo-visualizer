# Algo Lab

A small DSA visualizer made with plain HTML, CSS and JavaScript.

## Algorithms
- Sorting: Selection Sort, Quick Sort, Merge Sort
- Searching: Linear Search, Binary Search
- Graph: BFS, DFS

## How to use
Open `algolab.html` in a browser, pick an algorithm from the left menu and press Run.
For the search algorithms, type a number that is visible in one of the bars.
